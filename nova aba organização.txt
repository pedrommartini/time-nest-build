==================================================
1. OBJETIVO DA ALTERAÇÃO
==================================================

Substituir a função atual de TasksView.tsx por uma área mais ampla chamada:

ORGANIZAR

A aba Organizar passa a ser a central de consulta e gerenciamento de:

- Tarefas
- Eventos
- Projetos

A estrutura principal será composta por dois modos dentro da mesma aba:

1. Feed
2. Projetos

A troca entre Feed e Projetos deve funcionar de duas formas:

- toque nas tabs superiores;
- swipe horizontal para esquerda/direita.

IMPORTANTE:

"Projeto" NÃO é um terceiro tipo de item do Feed.

Todo item do Feed continua sendo obrigatoriamente:

- Evento
OU
- Tarefa

Projeto é apenas uma organização/pasta à qual uma tarefa ou evento pode pertencer.

Exemplo:

Editar vídeo do projeto
Tipo: Tarefa
Projeto: Trabalho

Jantar com cliente
Tipo: Evento
Projeto: Trabalho

==================================================

Exemplo:

const feedItems = useMemo(() => {

  const taskItems =
    tasks.map(task => ({
      type: 'task',
      data: task
    }))

  const eventItems =
    events.map(event => ({
      type: 'event',
      data: event
    }))

  return [
    ...taskItems,
    ...eventItems
  ]

}, [tasks, events])

64. RESULTADO ESPERADO
==================================================

A antiga aba "Tarefas" deve evoluir para uma central chamada:

ORGANIZAR

Ela deve funcionar como uma visão estrutural complementar à Timeline.

Timeline:
"Quando as coisas acontecem."

Organizar:
"O que existe e como está organizado."

Foco:
"O que estou fazendo agora."

Perfil:
"Como o aplicativo funciona para mim."


A experiência final deve preservar o DNA visual do TimeNest:

- calma;
- leve;
- mobile-first;
- simples;
- intuitiva;
- amigável para TDAH;
- sem excesso de informação.

O Feed deve permitir compreender tarefas e eventos rapidamente.

Projetos devem funcionar como pastas inteligentes para agrupar tarefas e eventos relacionados.

O vínculo com projeto nunca muda a identidade básica do item:

Tarefa continua sendo tarefa.
Evento continua sendo evento.

Projeto apenas adiciona contexto.
