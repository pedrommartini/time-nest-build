# TimeNest — Pacote de Referência dos Alarmes

Esta pasta foi preparada para ser anexada ao Antigravity.

## Conteúdo

- `ALARME_ESPECIFICACAO.md`: resumo do brainstorm, comportamento dos alarmes, estados, UX, som, vibração, acessibilidade e regras visuais.
- `imagens/`: referências visuais aprovadas e variações do sistema.

## Instrução para o Antigravity

Use este material para criar primeiro um **plano de implementação** do sistema de alarmes do TimeNest.

A direção funcional e visual deste pacote deve ser preservada. A arquitetura técnica pode ser escolhida livremente pelo Antigravity de acordo com a codebase existente:

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Capacitor

Componentes atuais relacionados:
- `AlarmOverlay.tsx`
- `ActiveEventPill.tsx`
- `TimelineEvent.tsx`
- `EventDetailDrawer.tsx`

As referências visuais não são pixel-perfect obrigatórias. Elas definem principalmente hierarquia, linguagem visual, simplicidade, intensidade e comportamento esperado.
